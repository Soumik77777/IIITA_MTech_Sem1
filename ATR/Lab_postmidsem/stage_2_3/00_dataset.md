# Dataset

## Soumik Bhattacharyya, MDE2026005

## **Topic:** Single-LLM Versus Multi-Agent Debate Systems for Scientific Hypothesis Generation

## Description

This work develops and compares single-LLM and multi-agent systems for identifying research gaps and generating scientific hypotheses related to **trimmed k-means**. The initial prototypes are being tested on a collection of 17 papers gathered using ChatGPT and Semantic Scholar. In a subsequent iteration, the collection is intended to be expanded using Research Rabbit, Litmaps, and OpenAlex. This document records the papers currently included in the dataset.

### Additional Notes

Paper discovery will be automated in future iterations. The following resources may support paper discovery, inspiration retrieval, and evaluation:

- [AI Idea Bench](https://ai-idea-bench.github.io/): Contains influential AI papers and their motivating papers, together with an evaluation framework for generated research ideas.
- [ResearchBench](https://github.com/ankitala/ResearchBench): Provides paper records and tasks for inspiration retrieval, hypothesis composition, and hypothesis ranking. It also includes a small test subset for initial experiments.
- [OpenAlex](https://openalex.org/): Provides an API for scholarly metadata and citation information.
- [arXiv](https://info.arxiv.org/help/api/index.html): Provides an API for searching and retrieving metadata for arXiv papers.
